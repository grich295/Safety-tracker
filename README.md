# Safety Tracker v1

Separate lightweight compliance tracker for uploaded H&S documents and training evidence.

## Included
- Admin / Manager / User roles
- Risk Assessment, COSHH, SSW, Policy, Procedure and Other document categories
- Upload finished documents; no document authoring
- Document versions with Current / Superseded history
- Document review dates
- Assign documents to people
- One-off or recurring sign-off frequency: 3/6/12/24 months or custom days/months/years
- Optional fresh sign-off when a new document version is published
- My Safety employee dashboard
- Ad-hoc Training, Toolbox Talks, Induction, Refresher and Other sessions
- Multiple supporting files per training session
- Per-training refresher/sign-off frequency
- Training review dates
- Individual electronic sign-off timestamp and statement snapshot
- People management with invite, Admin/Manager/User roles and disable/re-enable
- Reports: outstanding, sign-off histories, training matrix and review dates
- JSON database backup
- Private Supabase Storage bucket for uploaded files
- PWA/static GitHub Pages deployment

## Deliberately not included in v1
Incident reporting, inspections, permits, equipment checks, accident investigations, document authoring and any Inventory Tracker integration.
