Upload ALL files in this ZIP to the Safety Tracker repository root.

DATABASE / EDGE FUNCTION:
Already updated. Do not run SQL manually.

PROFILE PERMISSION:
People & Access -> Edit access now includes:
  [ ] Can carry out instructor-led training

USE IT FOR:
- Supervisors
- experienced team members
- other suitable people who should deliver training without becoming a full Safety Manager

RULES:
- Department Manager remains the DEFAULT responsible owner for each employee's instructor-led training.
- Admin / Manager can always deliver instructor-led training.
- A user with "Can carry out instructor-led training" ticked can deliver for employees in their own Department(s).
- The permission does NOT make them responsible for everybody's training.
- The person who actually records attendance remains the ACTUAL instructor in the evidence trail.
- Manual responsibility override still exists and can be used where needed.
- Whole-site training still allocates responsibility by each trainee's Department Manager.

Includes the previous Dynamic Groups and one-login/cache fixes.
