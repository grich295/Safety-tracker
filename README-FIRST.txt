BEHAVIOUR:
- Instructor-led training for the whole site is split automatically by trainee department.
- The trainee's Department Manager is the DEFAULT responsible owner.
- Department Managers can see/use the Instructor queue for their departments.
- A Manager/Admin can manually change the responsible manager for an individual assignment.
- The override changes responsibility/ownership only.
- ANY authorised Manager/Admin can still deliver training, even when someone else is responsible.
- Whoever records attendance is stored as the ACTUAL instructor for the evidence trail.
- If a trainee has no Department Manager configured, responsibility falls back to Any Manager/Admin.
- Employee acknowledgement/sign-off remains the employee's own step after attendance is recorded.
